## Project Description
This project is a YouTube Video Downloader developed using Python and yt-dlp.
It allows users to extract video details and download videos using a YouTube URL.

## Features
- Extract video title
- Display channel name
- Display video duration
- Download videos using a YouTube URL
- Save downloaded videos

## Technologies Used
- Python
- yt-dlp
- Google Colab
- Deno JavaScript Runtime

## How to Run
1. Open the notebook in Google Colab.
2. Install the required packages.
3. Run the code cells.
4. Enter a YouTube video URL.
5. Download the video.

## Output
The program displays video details and downloads the selected video.
